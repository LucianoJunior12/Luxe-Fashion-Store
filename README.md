# Luxe Fashion Store

Landing page profissional para a marca **Luxe** &mdash; moda feminina com design atemporal, elegância e sofisticação.

## Tecnologias

- HTML5
- CSS3 (animações, gradientes, design responsivo)
- JavaScript (scroll reveal, navegação interativa)
- Font Awesome (ícones)
- Google Fonts (Playfair Display + Inter)

## Funcionalidades

- Layout responsivo (mobile-first)
- Animações suaves de scroll (reveal)
- Navegação sticky com efeito de scroll
- Seções: Hero, Coleção, Sobre, Diferenciais, Newsletter
- Integração com redes sociais

## Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
